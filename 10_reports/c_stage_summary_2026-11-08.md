## 1. 一句话结论

六个样本共组装出 **12,016 条病毒 contigs（51.9 Mb）**，其中 **202 条达到中高质量（完整性 ≥50%）**，
分类上 **95.8–97.8% 属于有尾噬菌体纲 Caudoviricetes**，六个样本高度一致。
用统一参考做丰度加权后，**观察到清晰的季节结构**：同季节样本的群落相似度是跨季节的 6 倍
（Jaccard 0.186 vs 0.031），冬季存在 **87 个核心 vOTU** 和多个高丰度季节特异病毒
（冬季 RPKM 100–260，夏季降至 0–1）。
但冬夏样本来自**六只不同的鳄鱼、无任何配对**，因此该结构无法归因于季节本身——
这是设计层面的限制，不是分析能补救的（见第 3、8 节）。

## 3. 季节差异：存在/缺失分析不支持，**丰度加权后明显**

同一批数据，两种分析方法给出不同结论——这本身就是必须说清楚的一点。

### 3.1 未加权（vOTU 存在/缺失）

基于"该 vOTU 是否在某样本中被组装出来"，同季节配对 Jaccard 均值 0.041、跨季节 0.008；
但同季节的均值被 S2–S3（0.180）单独拉高，其余配对都在 0.03 以下。**这个层面看不出稳定结构。**

### 3.2 丰度加权（RPKM ≥ 1 视为检出）

用 6 个样本的 reads 比对到统一的 9,980 个 vOTU 代表序列，得到丰度矩阵后重算：

|  | W1 | W2 | W3 | S1 | S2 | S3 |
|---|---|---|---|---|---|---|
| **W1** | 1.000 | 0.192 | 0.177 | 0.073 | 0.008 | 0.010 |
| **W2** | | 1.000 | 0.124 | 0.061 | 0.003 | 0.003 |
| **W3** | | | 1.000 | 0.072 | 0.022 | 0.023 |
| **S1** | | | | 1.000 | 0.004 | 0.006 |
| **S2** | | | | | 1.000 | **0.611** |
| **S3** | | | | | | 1.000 |

**同季节均值 0.186，跨季节均值 0.031，相差 6 倍。** 若剔除离群的 S1，差距扩大到 24 倍（0.276 vs 0.012）。

| 六样本均检出 | 5 |

冬季核心明显更多。其中几个高丰度 vOTU 在夏季几乎消失：

前三个是**冬季特异的高丰度病毒**（RPKM 100–260，夏季降到 0–1），最后一个六个样本都有。
这些是真实存在的季节信号，不是统计假象。

### 3.4 但结论仍然不能写成"季节导致差异"

三个理由：

1. **季节与个体完全混淆**（第 8 节）：冬夏是六只不同的鳄鱼，没有任何配对。
   观察到的差异既可能来自冬眠禁食，也可能来自"这六只恰好如此"，本设计无法区分。
2. **n=3**，不做统计检验，6 倍差距在 n=3 时不足以排除个体偶然性。
3. **S1 是夏季组里的异类，但原因已查明**（见 3.5）：它的 GC 含量与冬季样本同组，
   病毒群落也偏向冬季型，提示**个体生理状态与日历季节不一致**。

**可写的表述**：在丰度加权层面观察到清晰的季节结构（同季节群落相似度是跨季节的 6 倍，
冬季存在 87 个核心 vOTU 及多个高丰度季节特异病毒），但受采样设计限制，无法将该结构归因于季节本身。

### 3.5 S1（个体 F5）诊断：日历季节 ≠ 生理状态

S1 在所有分析里都偏离夏季组。逐项排查：

| 检验 | 结果 | 判定 |
|---|---|---|
| 读段质量 | 长度 125 bp、N 占 0%、平均 Q 40.5（六样本最高）、无降解迹象 | 非数据质量问题 |
| 组装表现 | contigs 28,117 条、N50 6.4 kb（六样本最高） | 非组装失败 |
| **GC 含量** | **读段 46.6%、contig 47.3%**，与冬季三只（45.3–50.3%）同组；S2/S3 仅 39–40% | **关键差异** |
| 病毒 reads 占比 | 2.14%（最低），与冬季（2.62–3.91%）同档 | 与 GC 分组一致 |

**GC 与病毒丰度呈强负相关**：GC 39–40% 的 S2/S3 病毒 reads 占 12.8–15.2%，
GC 45–50% 的其余四个只有 2.1–3.9%。

结合原文的生理学框架可以给出一个自洽解释：

> 原文报告冬眠（禁食）期 *Bacteroides* 增加、活动（摄食）期 *Fusobacteria* 主导。
> *Fusobacteria* 是典型低 GC（约 30–35%），*Bacteroides* 约 40–45%。

- **S2/S3** → 低 GC（39–40%）、病毒多样且丰度高 = **典型活动期群落**
- **W1/W2/W3** → 高 GC（45–50%）= **冬眠期群落**
- **S1（F5）** → 高 GC（46.6%）+ 低病毒 = **夏季采样，但群落仍是冬眠型**

**推论：F5 这只个体在 2015-07 采样时，可能尚未完成从禁食到摄食的生理转换。**
这解释了它为何既不像夏季的 S2/S3，又比冬季样本更接近冬季型。

### 3.7 由此得到的完整图景

| 个体 | 采样时间 | 生理状态（推断） | 群落特征 |
|---|---|---|---|
| F1、F2、F6 | 2016-01 | 冬眠禁食 | 高 GC、病毒中等、彼此相似（0.89–0.97） |
| F3、F4 | 2015-07 | 活动摄食 | 低 GC、病毒丰富、彼此高度相似（0.995） |
| **F5** | **2015-07** | **仍为冬眠型（未转换）** | 高 GC、病毒少、菌群像冬季（0.80） |

**"夏季采样"不等于"活动期生理状态"。** F5 证明了两者可以脱钩——
这既解释了 S1 为何在所有分析里都是离群值，也说明原文按采样季节分组存在个体误分类。

### 3.8 为什么两种方法给出相反结论

- **存在/缺失分析**依赖"病毒能否被组装出来"，而组装受丰度、测序深度、群落复杂度共同影响。
  低丰度病毒拼不出来就记为"缺失"，把真实的共享关系抹掉了。
- **丰度加权**直接把 reads 比对到统一参考，不依赖每个样本各自组装，灵敏度高得多。
  这解释了为什么 S2–S3 从 0.180 升到 0.611、W1–W3 从 0.029 升到 0.177。

**方法学教训：做病毒组跨样本比较，必须用统一参考 + 丰度加权，不能只比 contig 的有无。**

## 6. 与 M1 的衔接，以及一个必须解释的矛盾

| 层次 | 指标 | 数值 |
|---|---|---|
| M1（reads） | 病毒样 reads | 0.675–0.702%（六样本几乎持平） |
| M1（reads） | 病毒特异 reads | 0.089–0.122% |
| C（contigs） | 病毒 contigs 占比 | 1.41–13.34% |
| C（contigs） | 中高质量基因组 | 10–72 条/样本 |

**矛盾**：reads 层面六个样本几乎一模一样（0.675–0.702%），组装层面却差 9 倍（1.41–13.34%）。

**最可能的解释**：两层的检测原理不同。
M1 用 DIAMOND blastx 打 RVDB，检测的是"与**已知**病毒蛋白的氨基酸相似性"——
数据库里没有的病毒（肠道里绝大多数是未知噬菌体）根本检测不到，所以各样本被压平在同一个低水平。
C 阶段用 geNomad（marker 基因 + 神经网络分类），能识别远缘和新型病毒，
因此更能反映真实的病毒丰度差异。

**这个矛盾本身就是一条证据**：它说明 read 层面的 0.69% 是"数据库覆盖率的下限"，不是生物学真实值。
正文里应当把两层结果并置解释，而不是挑一个用。

## 7. vOTU 聚类：病毒组高度个体特异

12,016 条病毒 contigs 经 CD-HIT-EST（95% ANI / 85% 覆盖度）聚类为 **9,980 个 vOTU**，
仅 16.9% 的 contig 被归并——说明这批数据里的病毒几乎互不重复。

### 7.1 共享模式

| 出现的样本数 | vOTU 数 | 占比 |
|---|---|---|
| 1 个（样本特有） | 8,430 | **84.5%** |
| 2 个 | 1,495 | 15.0% |
| 3 个 | 43 | 0.4% |
| 4 个 | 11 | 0.1% |
| 5 个 | 1 | <0.1% |
| 6 个（核心） | **0** | 0 |

**在 vOTU 定义（95% ANI / 85% 覆盖度）下，没有任何一个 vOTU 出现在六个样本中。** 84.5% 的 vOTU 只属于单个个体。

但这是一条**存在/缺失口径**的结果，且 vOTU 定义相当严格。改用丰度加权后（reads 比对到统一参考），
共享关系显著上升：同季节 Jaccard 从 0.04 升到 0.19，六样本共有的 vOTU 从 0 个变成 5 个（第 3.5 节）。
**两种口径给出的"个体特异性"程度不同，正文引用时必须说明用的是哪一种。**

|  | W1 | W2 | W3 | S1 | S2 | S3 |
|---|---|---|---|---|---|---|
| **W1** | 1.000 | 0.013 | 0.029 | 0.014 | 0.004 | 0.004 |
| **W2** | | 1.000 | 0.015 | 0.020 | 0.000 | 0.000 |
| **W3** | | | 1.000 | 0.017 | 0.006 | 0.007 |

**S2 与 S3 的相似度（0.180）是其他任意样本对的 6–45 倍**，其余所有配对都低于 0.03。

这个结构说明三件事：

1. **在这个未加权口径下，季节解释不了病毒组组成**——S1 同为夏季，与 S2/S3 的相似度只有 0.003 / 0.006，
   比它和冬季样本还低。**但丰度加权后结论相反**（第 3.5 节），差异来自方法而非数据。
2. **S2 与 S3（个体 F3、F4）共享一个病毒群落**：两者个体不同、同期采样（2015-07），
   相似度却是其他配对的数倍，最可能反映同圈舍饲养环境下的病毒共享或个体间传播。
3. 其余样本在未加权口径下彼此几乎不共享（≤0.03）；加权后冬季三只升至 0.12–0.19，说明共享是存在的，
   只是没能在组装层面体现出来。

### 7.3 季节专属 vOTU

| 类别 | vOTU 数 |
|---|---|
| 仅冬季样本出现 | 1,454 |
| 仅夏季样本出现 | 8,414 |
| 冬夏共有 | 112 |

"夏季专属"数量大（8,414）看似支持季节假说，但**这是 S2/S3 病毒丰度高的副产品**：
S2、S3 各自的 vOTU 就有 4,912 和 4,346 个，而 S1 只有 714 个。

**而丰度加权后，季节核心 vOTU 反而是冬季更多（87 vs 16）**——与"夏季更丰富"的直觉相反。
这提示"contig 数量多"与"核心群落稳定"是两件不同的事：S2/S3 病毒多样但群落均匀
（Top10 仅占 7–9%），冬季病毒种类少但有稳定的核心成员。

**结论：存在/缺失口径下的样本差异主要反映组装与丰度，而非季节；季节结构要在丰度加权后才显现（第 3 节）。**

## 8. 数据来源与设计限制（关键）

### 8.1 数据出处

本研究使用的 6 个宏基因组样本来自公共数据库，**不是自行采样**：

> Tang K-Y, Wang Z-W, Wan Q-H, Fang S-G. *Metagenomics Reveals Seasonal Functional Adaptation of the
> Gut Microbiome to Host Feeding and Fasting in the Chinese Alligator.*
> Front Microbiol. 2019;10:2409. **PMID: 31708889**. doi: 10.3389/fmicb.2019.02409
> BioProject: **SRP315843**；样本采集地：中国浙江长兴（30.93 N, 119.74 E）

### 8.2 六个样本的真实身份（从 ENA 元数据核实）

| 标签 | run | alias | 个体 | 采样日期 | 组 |
|---|---|---|---|---|---|
| W1 | SRR14300938 | H.F2_300 | **F2** | 2016-01 | 冬眠期（H = hibernating） |
| W2 | SRR14300939 | H.F1_300 | **F1** | 2016-01 | 冬眠期 |
| W3 | SRR14300942 | H.F6_300 | **F6** | 2016-01 | 冬眠期 |
| S1 | SRR14300940 | A.F5_300 | **F5** | 2015-07 | 活动期（A = active） |
| S2 | SRR14300941 | A.F4_300 | **F4** | 2015-07 | 活动期 |
| S3 | SRR14300943 | A.F3_300 | **F3** | 2015-07 | 活动期 |

**冬季是 F1/F2/F6，夏季是 F3/F4/F5——六个互不相同的个体，没有任何一个个体的冬夏配对。**
这比"n=3"严重得多：**季节效应与个体效应完全混淆（completely confounded）**。
任何冬夏差异都无法归因于季节，因为个体同时换了。

原 study 共 30 个 run：24 个 16S 扩增子（4 个肠段 × 2 季节 × 3 个体）+ 6 个宏基因组（仅 F 组粪便）。
16S 的 F 组也是同样 6 个个体，说明这是原始设计，不是数据下载不完整。

### 8.3 这对结论的约束

1. **不能做季节推断**。正确表述是"本设计无法分离季节与个体效应"，而非"季节没有影响"。
2. **S2 与 S3 的 0.180 相似度不是批次伪影**——它们是不同个体（F3、F4）、同期采样。
   更可能是同圈舍/同饲养单元的病毒共享，或个体间传播。
3. **与原文的对照很有意思**：原文在细菌层面报告了"核心肠道菌群"（Proteobacteria、Fusobacteria、
   Bacteroidetes、Firmicutes 为主）并检出季节重构；而我们在病毒层面得到的是
   **9,980 个 vOTU 中零个六样本共有**。即：**细菌有核心，病毒没有核心**，
   病毒组的个体特异性远高于细菌。

## 9. 宿主预测（iPHoP 全库，六路证据融合）

### 9.1 从 CRISPR-only 到全库

第一轮因磁盘不足（本机 111 GB，iPHoP 库 116.9 GB）只跑了 CRISPR spacer 模块，得 24/202（11.9%）。
第二轮把库下到内置 2T 盘，跑完整 iPHoP，融合**六路独立证据**：

| 证据 | 原理 | 本轮参与 |
|---|---|---|
| blastn vs 宿主基因组 | 病毒序列在 14,528,473 条宿主基因组序列（307 Gb）中出现 | 76 |
| CRISPR spacer | 宿主 CRISPR 阵列里的 spacer 精确匹配 | 9 |
| WIsH | 6 万个 k-mer 模型的寡核苷酸组成匹配 | 参与打分 |
| VHM / PHP | 病毒–宿主匹配矩阵与模型 | 参与打分 |
| RaFAH | HMM + Diamond + 随机森林 | 42 |
| iPHoP-RF | 上述证据的随机森林整合 | 108 |

版本关键：**必须用 iPHoP 1.2.0**。1.4.x 要求库含 `rewish_models`（1.3+ 的 `_rw` 新库格式），
遇 Sept_2021 老库会直接 `sys.exit(1)`。

### 9.2 结果

| 指标 | CRISPR-only | **全库六路** |
|---|---|---|
| 有宿主预测的基因组 | 24 / 202（11.9%） | **83 / 202（41.1%）** |
| 属级记录数 | 14 | 128 |
| 置信度中位 | — | **93.8**（范围 90–100） |

按 CheckV 质量：Complete 34.5%（10/29）、High 43.8%（21/48）、Medium 41.6%（52/125）——**覆盖不依赖基因组完整性**。

宿主门分布（按记录）：Proteobacteria 69、Firmicutes_A 26、Bacteroidota 22、Fusobacteriota 6、
Thermoproteota 2、Desulfobacterota 1、Actinobacteriota 1、Firmicutes 1。

宿主属 Top 12：***Bacteroides* 19、*Escherichia* 13、*Aeromonas* 9、*Citrobacter* 6、*Edwardsiella* 6**、
*Clostridium* 5、GCA-900066495 4、*Niameybacter* 4、*Plesiomonas* 4、*Salmonella* 3、*Vibrio* 3、*Hafnia* 3。

83 条中 **59 条为单一属、23 条为多属**（最多 6 个），多属者多为相近属（如 *Citrobacter*/*Enterobacter*）。

### 9.3 前噬菌体的宿主——本轮最有价值的结果

**33 条前噬菌体中 21 条（64%）定位到宿主属**，远高于非前噬菌体的 37%（62/169）——因为它们本就嵌在宿主染色体里。

| 前噬菌体宿主属 | 条数 |
|---|---|
| *Bacteroides*（冬眠期优势菌） | 7 |
| ***Edwardsiella*** | 5 |
| ***Escherichia*** | 4 |
| ***Aeromonas*** | 4 |
| *Niameybacter*、*Yersinia* | 各 2 |
| *Citrobacter*、*Hafnia*、*Serratia*、*Pectobacterium*、*Roseburia* 等 | 各 1 |

**21 条中 11 条（52%）的宿主属包含已知鳄类条件致病菌**（*Edwardsiella*、*Aeromonas*、*Citrobacter*、*Yersinia*、
*Hafnia*、*Serratia*、*Pectobacterium*）。

这一段对"前噬菌体是否是条件致病开关"的锚点是直接的可行性证据：**过去 33 条前噬菌体只有 1 条知道宿主，
现在有 21 条**。宿主身份是这类研究的前提，没有它就无法谈"哪种菌被前噬菌体改写了表型"。

### 9.4 样本间差异（需注意）

| 样本 | 覆盖率 |
|---|---|
| W1 / W2 / W3（冬眠） | **68.4% / 70.0% / 65.4%** |
| S1 / S2 / S3（活动） | 41.2% / 27.8% / 32.8% |

冬季样本的病毒明显更容易匹配到已知宿主。合理解释是**冬眠期群落以 *Bacteroides* 为主**（原文：粪便 55.82% vs 8.19%），
而 *Bacteroides* 噬菌体在数据库中收录充分、且多为温和噬菌体（整合态，随宿主基因组一起被 blastn 找到）。
夏季 S2/S3 病毒多样性高、以未知噬菌体为主，因此匹配率低。

**这提示"覆盖率"本身带有群落组成的偏倚**，不能简单当作方法灵敏度指标跨样本比较。

### 9.5 局限

1. **仍未覆盖 119 条（58.9%）**：属级置信度阈值 90。未命中不等于无宿主，只说明六路证据都指向不了已知属。
2. **数据库版本较旧**（Sept 2021），对 2021 年后新收录的宿主—病毒对不敏感。
3. **属级分辨率**：输出到属（m90），未到种。同一属内不同种的致病性差异可能很大，这一点对"条件致病"命题是实质限制。
4. 前噬菌体宿主 21 条中 7 条为多属，需人工判读（优先取与 blastn 一致者）。

## 10. 方法与参数

```
组装      MEGAHIT 1.2.9  --min-contig-len 1000 -m 0.5 -t 8
识别      geNomad 1.13.0  end-to-end --splits 4（MMseqs2 18.8cc5c，DB v1.9）

运行环境  Debian 13 / 8 核 / 125 GB 内存
```

## 11. 局限与待办

**局限**
1. **最大限制在设计层面**：冬夏两组是六个不同个体（F1/F2/F6 vs F3/F4/F5），
   季节与个体完全混淆（第 8 节）。**即使丰度层面观察到清晰的季节结构，也无法归因于季节本身。**
2. **两种口径结论不同**（第 3.5 节）：存在/缺失看不出季节结构，丰度加权后 6 倍差异。
   正文引用时必须标明用的是哪一种，不能混用。
3. 个体间病毒占比相差近 9 倍（1.41–13.34%），需要更多个体才能刻画分布。
4. S2 与 S3 的 0.611 相似度（加权后）已确认不是批次伪影（不同个体、同期采样），
   但其成因（同圈舍？个体间传播？）在元数据中没有披露，无法进一步判断。
5. **宿主预测覆盖 41.1%（83/202）**，属级置信度 ≥90；仍有 119 条无宿主归属，
   且分辨率只到属，不足以支撑"哪个种会致病"的判断。
6. S1（个体 F5）经技术排查无异常，但其 GC（46.6%）与病毒群落均呈冬眠型（第 3.5 节），
   提示采样时生理状态可能尚未转换。**该推断基于 GC 的间接证据，需 16S 群落数据或摄食记录直接验证。**
7. 未做生活方式（裂解/溶源）判定。
8. 原始数据来自 2015–2016 年、HiSeq 2500 平台，跨研究比较需谨慎。
