# 前噬菌体 cargo 注释

**日期** 2026-11-09　|　**对象** 202 条中高质量病毒基因组中的 **33 条前噬菌体**（另有 44 条来自非中高质量 contig，作补充）
**方法** geNomad 基因注释 + diamond 比对 VFDB（毒力）与 CARD（耐药）
**用途** 为"前噬菌体是否为条件致病菌的开关"这一锚点提供第一批分子证据

---

## 1. 一句话结论

33 条前噬菌体携带 **35 个宿主来源辅助基因**，**23 条（70%）至少带一个**，以**代谢辅助基因**和**DNA 修饰/抗防御**为主；
**未检出任何获得性抗生素抗性基因**；唯一一组直接影响宿主—病原互作的 cargo 是 **W1 一个 Aeromonas 前噬菌体上的 katA + sodCI（过氧化氢酶 + 超氧化物歧化酶）**，
两个基因都是细菌对抗宿主氧化爆发的经典武器。

---

## 2. 测了什么

| 项 | 数值 |
|---|---|
| 前噬菌体总数（geNomad 预测） | 77 条（六样本合计），其中 **33 条落在 202 条中高质量基因组内** |
| 基因数（33 条） | 1,355 |
| 有功能注释的基因 | 483（**36%**，中位每条 39%，范围 5–81%） |
| 判为宿主来源 cargo 的基因 | **35**（占已注释 7.2%） |
| 携带 ≥1 cargo 的前噬菌体 | **23 / 33（70%）** |

**判定规则**（脚本 `workflow/cargo_annotate.py`）：

1. 带噬菌体标识的基因（`terminase`/`capsid`/`tail`/`holin`/`lysin`/`integrase`/`phage`…）→ 噬菌体固有，**不计 cargo**；
2. 其余有注释的细菌功能基因 → 宿主来源 cargo，按功能分 6 类；
3. 距前噬菌体两端 **<500 bp** 的基因标 `boundary`（可能是 att 位点附近带进来的宿主侧翼序列），单独标记不直接排除；
4. VFDB/CARD 阈值：一致度 ≥30% 且覆盖 ≥70%（RGI loose 水平）；已知看家基因命中（ligA、clpP、rcsB）**不计入毒力 cargo**。

## 3. cargo 构成

| 类别 | 基因数 | 涉及前噬菌体 | 占 33 条比例 |
|---|---|---|---|
| 代谢 AMG | 19 | 16 | 48% |
| 抗防御 / DNA 修饰 | 7 | 7 | 21% |
| 细菌调控 | 4 | 4 | 12% |
| 转座 / 移动元件 | 2 | 2 | 6% |
| **毒力 / 氧化应激** | **2** | **1** | **3%** |
| **毒素-抗毒素** | **1** | **1** | **3%** |
| **合计** | **35** | **23** | **70%** |

### 3.1 代谢辅助基因（最普遍的一类）

| 基因功能 | 条数 | 生态学含义 |
|---|---|---|
| ClpP 蛋白酶亚基 | 5 | 蛋白降解，可能协助噬菌体接管宿主蛋白酶体 |
| 氰酸酶 cyanase | 3 | 氰酸盐解毒，改变局部代谢环境 |
| 几丁质酶 chitinase | 2 | 碳源获取 |
| 蛋白酶体盖亚基 RPN8/RPN11 | 2 | 降解宿主蛋白 |
| D-丙氨酰-D-丙氨酸羧肽酶 | 2 | 细胞壁修饰 |
| N4-乙酰胞嘧啶脱氨酶 | 2 | 核苷酸修饰 |
| 其他（胸苷酸合成酶、dTMP 激酶、核糖核苷酸还原酶、酸性磷酸酶、过氧化物酶包封蛋白等） | 3 | 核苷酸/磷酸/氧化应激代谢 |

这些是典型的**辅助代谢基因（AMG）**——前噬菌体借宿主代谢为自己的复制服务，同时也可能改变宿主的代谢表型。

### 3.2 抗防御 / DNA 修饰

`dcm`（DNA 胞嘧啶甲基转移酶）3 条、`dam`（腺嘌呤甲基化酶）2 条、N6-腺嘌呤甲基转移酶 1 条、
**抗限制蛋白 ArdC 1 条**。

这一类的功能是**保护噬菌体 DNA 不被宿主限制系统切掉**。ArdC 是明确的抗限制蛋白，
出现在 `W2|k141_3134`（宿主 *Bacteroides*）上。

### 3.3 毒力 / 氧化应激（最有价值的一组）

`W1|k141_27977|provirus_15669_72479`（56.8 kb，宿主 ***Aeromonas***）携带两个相邻基因：

| 基因 | 比对 | 一致度 | 覆盖 | VFDB 分类 |
|---|---|---|---|---|
| g43 **katA** 过氧化氢酶 | VFG037029 | 43.9% | 94% | KatA (VF0454) — Stress survival |
| g45 **sodCI** 超氧化物歧化酶 | VFG000463 | 54.3% | 85% | SodCI (VF0109) — Stress survival |

值得强调的是 sodCI 的参考序列本身就叫 **"Gifsy-2 prophage: superoxide dismutase"**——
这是沙门氏菌 Gifsy-2 前噬菌体携带的经典毒力基因，是"前噬菌体 cargo 直接提升病原适应度"的教科书案例。

**katA + sodCI 的组合意味着**：这个前噬菌体赋予了 *Aeromonas* 宿主同时分解 H₂O₂ 和超氧阴离子的能力，
而这正是中性粒细胞杀灭胞内菌的两条主要途径。若该宿主是条件致病菌，这两个基因就是"发病开关"最直接的分子候选。

另有 1 条 heme 摄取系统半胱氨酸水解酶（VF0650，40.5%/95%）落在 `W1|k141_57104`（18.3 kb，不在 33 条内），
提示铁获取能力也可能是这批前噬菌体的 cargo 之一。

### 3.4 毒素-抗毒素

`W1|k141_69425|provirus_28378_55342`（27.0 kb，宿主 ***Hafnia***）gene 53 为 **ParE-like toxin domain**，
与下游 dam 甲基化酶（g52）、羧肽酶（g36）、N4-乙酰胞嘧啶脱氨酶（g51）构成一个 4 基因的辅助模块，
是 33 条里 **cargo 密度最高的一条（1.48 个/10 kb）**。

ParE 属 II 型 TA 系统的毒素端。TA 系统的经典功能是**维持质粒/前噬菌体在宿主群体中的稳定存在**（post-segregational killing）——
也就是说，这条前噬菌体具备"赖着不走"的机制。这与"开关"假说的关系是间接的，但很关键：
**稳定的溶源状态是后续被诱导的前提**。

## 4. 抗性基因：明确的阴性结果

三重检验，结论一致——**这批前噬菌体不携带获得性抗生素抗性基因**：

| 检验 | 方法 | 结果 |
|---|---|---|
| ① geNomad 自带 AMR 注释 | 2678 个基因的 `annotation_amr` 列 | **0 条** |
| ② CARD 蛋白同源比对 | 6,329 条 CARD 蛋白，≥30%/70% | 32 条命中，**0 条**属已知获得性家族（bla/tet/erm/sul/aph/aac/qnr/cat/mph/mef/van/mcr/fos…） |
| ③ 提高阈值到 ≥60% 一致 | CARD | 仅 5 条，全是 **gyrA 突变模型**（S1\|k141_45736，且不在 33 条内） |

CARD 里那些 `gyrA`/`gyrB` 条目是**染色体点突变模型**（喹诺酮耐药由靶基因突变产生），不是可转移的抗性基因；
把这类命中当成"噬菌体携带耐药基因"是常见误判。本次已单独标记为「突变模型（非获得性）」。

**这个阴性结果本身有意义**：与"噬菌体是 ARG 仓库"的流行印象相反，肠道前噬菌体的 cargo 主要不是抗性。
它提示在这套样本里，**前噬菌体的选择压力更可能来自宿主免疫（氧化爆发）而非抗生素暴露**。

## 5. 宿主与 cargo 的交叉

33 条前噬菌体的宿主归属（来自 iPHoP 全库预测）：

| 宿主属 | 前噬菌体数 | 是否条件致病菌 |
|---|---|---|
| *Bacteroides* | 4 | 共生 |
| *Aeromonas* | 3 | **是**（鳄类常见条件致病菌） |
| *Edwardsiella* | 2 | **是** |
| *Escherichia* | 2 | **是** |
| *Hafnia* | 1 | **是** |
| *Roseburia*、*Niameybacter*、*Chania* | 各 1–2 | 共生 |
| 无预测 | 11 | — |

| | 有 cargo | 无 cargo | 合计 |
|---|---|---|---|
| 宿主属含条件致病菌 | 7 | 3 | 10 |
| 其他 / 无预测 | 16 | 7 | 23 |

**条件致病菌宿主的前噬菌体并没有显著更高的 cargo 携带率**（7/10 vs 16/23）。
也就是说，cargo 的存在与宿主是否致病**不相关**——这与"开关"假说并不矛盾（开关假说要求的是
*特定 cargo* 而非 *cargo 数量*），但也意味着**不能靠 cargo 数量做区分**，必须看具体基因。

## 6. 局限（必须与结果一起读）

1. **注释率只有 36%**（基因层面 61% 无功能）。cargo 判定完全依赖已知同源，
   因此 **35 个是下限，不是真实数目**。未知基因里可能藏着更关键的 cargo。
2. **33 条前噬菌体没有一条被 CheckV 判为 Complete**（前噬菌体嵌在宿主染色体里，CheckV 给不出完整度）。
   这意味着 geNomad 划定的区间边界不完全可靠，**边界附近可能混入宿主侧翼基因**。
   已把距两端 <500 bp 的基因单独标记：33 条里共 **90 个（6.6%）**，其中只有 **1 个**被计入 cargo——
   说明边界污染对 cargo 清单的影响很小，但边界本身的不确定性仍是客观存在的。
3. **同源比对阈值敏感**。30–40% 一致度的命中（如 ligA 30.8%、bcrA 30–39%）多数是泛命中，
   本报告已把已知看家基因排除，但边界情况仍存主观判断。
4. **只有 DNA 层面**。宏基因组只能说"基因在不在"，**不能说明它是否表达、是否在被诱导时释放**。
   要回答"开关是否被打开"，必须加宏转录组或体外诱导实验（丝裂霉素 C / 亚抑菌浓度抗生素）。
5. **无 AMR 是"未检出"**，不等于绝对没有——CARD 覆盖的是已知抗性基因，新型机制检测不到。
6. **样本量**：33 条来自 6 个个体，且季节与个体在设计上完全混淆（见 C 阶段报告第 8 节），
   因此不能做"冬季 cargo 多于夏季"这类组间比较。

## 7. 这批结果在论证链里的位置

| 论点 | 现有证据 | 强度 |
|---|---|---|
| 前噬菌体普遍存在于肠道菌群 | 77 条前噬菌体 / 12,016 病毒 contigs；21/33 有宿主 | 强 |
| 前噬菌体携带宿主来源辅助基因 | 23/33 带 ≥1，35 个基因 | 中（受注释率限制） |
| 某些 cargo 可能增强条件致病菌适应度 | katA + sodCI（*Aeromonas*）；heme 摄取（W1） | **中—弱**（仅 1–2 例，无表达证据） |
| 前噬菌体不携带获得性抗性基因 | 三重检验一致为 0 | **强（阴性结论）** |
| 前噬菌体具备稳定溶源的能力 | ParE TA 1 例 + integrase 12/33 | 弱 |
| cargo 是否被诱导、是否改变宿主表型 | **无证据** | **缺口** |

**下一步要补的**：
1. **MAG 路线**（组装细菌基因组 → binning → 在 MAG 内预测前噬菌体）——解决 Complete 缺失与边界不可靠，同时把宿主身份从"预测"变成"确证"；
2. **宏转录组或诱导实验**——解决"开关打不打开"这个核心问题；
3. **扩大注释**（PHROGs / VOGDB / dbCAN）——把 36% 的注释率往上推，才能把 cargo 清单补全。
