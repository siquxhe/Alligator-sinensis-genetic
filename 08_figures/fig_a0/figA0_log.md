## 一、这张图要解决的问题

读者拿到「病毒占比 X%」时，默认这是一个客观测量值。这张图要说明：**它是四个决策的联合结果**，而四个决策在论文 Methods 里往往一句都不写。

## 二、四个维度与实测影响

| 维度 | 含义 | 选项 | 本批实测倍数 | 取自 |
|---|---|---|---|---|
| **分母** Denominator | 什么算 100% | 去宿主前全部 QC reads / 去宿主后 reads | **1.01×**（≤1.2%） | C2 / C6 |
| **参考空间** Reference space | 跟什么比 | RVDB-prot / 本地 vOTU / nr（文献） | **5.6×** | C5 / C2 |
| **类别筛选** Category filter | 哪些命中算数 | 任意病毒样命中 / 仅结构+复制转录 / 基因组级判定 | **7.1×** | C2 / C1 |
| **计数对象** Counting unit | 数 reads 还是片段 | reads 计数 / contig 计数 / RPKM 加权 | **5.4×**（含检测层面，非纯单位效应） | C4 / C2 |

四维组合的实测极值：**0.0891% – 15.23%**，总跨度 **171×**。

## 三、171× 必须分解（本轮新增）

171× 的两个端点分属不同样本与不同口径（0.0891 = W2/C1，15.23 = S3/C5），所以它同时含**定义效应**与**样本效应**：

| 量 | 数值 | 含义 |
|---|---|---|
| 同一样本内 C5/C1 | **22.2 – 124.8×** | 纯定义效应（样本固定） |
| C1 的跨样本极差 | **1.37×** | 纯样本效应（口径固定） |
| 两者相乘 | 124.8 × 1.37 = **171×** | 与总跨度一致 |

所以标题写成两句：主标题保留 171×，副标题明写「同一样本内定义本身已跨 22–125×，跨样本才到 171×」。**这样既保住冲击力，又不能被质疑"你只是挑了最小和最大的两个格子"。**

## 四、设计决策

1. **不画成流程图，画成四行平行决策**。这四个维度不是"先后步骤"，而是四个可独立选择的旋钮——画成流水线会误导读者以为有固定顺序。
2. **每个维度必须标注实测倍数**。读者能直接看到「类别筛选」（7.1×）比「分母」（1.01×）重要得多，不必四个都当回事。
3. **分母维度如实标 1.01×**。它不是"大约 1×"的含糊说法，而是实测值：本批去宿主实际只去掉 0.02–1.21% 的 reads，故 C2/C6 = 1.0002–1.0122。
   在图注里写明「not so in tissue」——在宿主占比高的样本（组织、血液）里这个维度可能变成主导，本批低是因为粪便样本本身宿主极少。
4. **「类别筛选」不叫「证据门槛」**。7.1× 不是"要求更多证据"造成的，而是"只保留结构 + 复制/转录两个功能类别"。被排除的代谢/持家类基因**同样是功能蛋白**，只是与细菌同源、无法判定来源——这是同源性问题，不是证据强度问题。术语与 Fig 2 的 `strict` / `broad` 保持一致。

## 四之二、第四轴的限定（2026-11-13 补）

C4/C2 = 5.4 倍**不能直接读作"计数单位"的效应**。该对比同时更换了计数单位与检测层面：C2 是 read 层的蛋白比对命中，C4 是 contig 层的基因组判定。

为拆开二者，另做了受控对照（`12_second_dataset/code/06_unit_test.sh`）：把每个样本的 reads 比对回**它自己的**病毒 contig 集，参考集完全相同、只换单位。已完成的样本上，contig 单位与 reads 单位之比约 **0.6**，方向与 5.4 倍相反。

因此图中该轴标注为 `incl. detection level`，5.4 倍应理解为这一轴的**上界**。正文 Results 5.2 有对应段落；Table 2 第 4 项与表注 (g) 同步说明。

## 五、诚实标注（已写入图注）

> Fold ranges are measured in this dataset with the other dimensions held fixed; **they are not strictly multiplicative.**

四个倍数不能直接相乘（1.01×5.6×7.1×5.4 = 217 ≠ 171），因为各比值来自不同样本与不同口径组合，口径不完全正交。图中只报单维度影响，不制造"合成倍数"的错觉。
