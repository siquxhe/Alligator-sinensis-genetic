# 校准：在有限条件下让测量最接近真值

**日期** 2026-11-16　|　**实验** 9 个已知真值的 spike 文库 × 2 个参考库 × 2 种口径
**数据** `13_calibration/code/spike_calibrate.py`，服务器 `/mnt/work/chicken/refcheck/spike/`

---

## 一、问题重新定位

前面的工作（B1、B 方案）只做到"哪条规则让数字变化多少"，以及"这个变化有多稳"。这些是必要的，但没有回答：

> **哪个规则的数字更接近真相？**

"接近"必须先有真值。可用的真值只有一种来源：**往样本里掺已知量的东西**。

## 二、设计：用浓度梯度同时反解背景与回收率

3 个纯培养噬菌体（T4 / Lambda / T7）掺入 W1 的 200 万对背景 reads，3 个水平（0.1% / 1% / 5%）× 3 重复 = 9 个文库，真值精确到 0.1000% / 1.0000% / 5.0000%。

同一规则、同一背景下，spike 只稀释背景：

```
est(f) = B·(1−f) + rec·f  =  B + (rec − B)·f
```

对 f 做线性回归：

| 回归量 | 含义 |
|---|---|
| **截距** | **B，背景基线**——该规则测到的"非 spike 病毒"水平 |
| **斜率** | rec − B |
| **由二者得** | 回收率 `rec = B + 斜率` |

于是**不需要任何外部真值**，只用 3 个浓度点就能同时解出背景与回收率。校准式：

```
f_cal = (est − B) / (rec − B)
```

## 三、结果：四个规则，四个截距，四个回收率

| 规则 | 背景基线 B | 回收率 rec | 线性 R² |
|---|---|---|---|
| PHROG / 宽（任意病毒命中） | 4.156% | **88.75%** | **1.000** |
| PHROG / 严（结构+复制） | 0.799% | **59.74%** | **1.000** |
| RefSeq / 宽 | 1.267% | **89.28%** | **1.000** |
| RefSeq / 严 | 0.335% | **55.07%** | **1.000** |

**四个 R² 全部为 1.000。** 线性模型不是近似，是精确成立——spike 只稀释背景、回收率与浓度无关，这一点被证实到小数点后三位。

## 四、校准效果：误差 ≤1.2%

| 规则 | 真值 0.1% | 真值 1% | 真值 5% |
|---|---|---|---|
| PHROG / 宽 | 0.100（**−0.2%**） | 1.000（0.0%） | 5.000（−0.0%） |
| PHROG / 严 | 0.099（−0.5%） | 1.001（0.1%） | 5.000（−0.0%） |
| RefSeq / 宽 | 0.099（−0.5%） | 1.001（0.1%） | 5.000（−0.0%） |
| RefSeq / 严 | 0.101（1.2%） | 0.998（−0.2%） | 5.000（0.0%） |

**四个规则、两个库、两种口径，校准后全部恢复到真值，最大误差 1.2%，多数低于 0.1%。**

## 五、真正的发现：不是"哪个规则更准"，而是"错在哪里、能不能改"

校准前，同一批数据的估计值与真值差得很远：

| 规则 | 真值 0.1% 时估计 | 偏离 | 真值 5% 时估计 | 偏离 |
|---|---|---|---|---|
| PHROG / 宽 | 4.240% | **高估 42×** | 8.386% | 高估 1.68× |
| PHROG / 严 | 0.858% | 高估 8.6× | 3.746% | **低估 0.75×** |
| RefSeq / 严 | 0.391% | 高估 3.9× | 3.072% | 低估 0.61× |

**偏差方向随浓度改变**：低占比时被背景抬高，高占比时被回收率压低。存在一个无偏交叉点 `f* = B / (B + 1 − rec)`，对 PHROG/宽约为 **27%**——远高于肠道样本的真实范围。

所以，真实数据（占比 0.1–5%）几乎全部落在"高估区"。这解释了为什么环境中报出的病毒占比往往偏高：**背景被当成了信号**。

## 六、最优规则怎么选：不是"最严格"，而是"校准后不确定度最小"

四个规则校准后同样准确（误差 ≤1.2%），差别在**代价**：

| 规则 | 回收率 | 校准放大倍数 1/rec | 含义 |
|---|---|---|---|
| PHROG / 宽 | 88.75% | **1.13×** | 检出九成，校准只放大 13% |
| RefSeq / 宽 | 89.28% | 1.12× | 同上 |
| PHROG / 严 | 59.74% | **1.67×** | 漏掉四成，校准放大 67% |
| RefSeq / 严 | 55.07% | **1.82×** | 漏掉近半，校准放大 82% |

**"严格口径更准确"这个直觉是错的。** 它的背景基线确实更低（0.8% vs 4.2%），但代价是回收率掉到 60%，校准时要乘 1.67 倍——**噪声同比例放大**。

正确判据是**校准后的残余不确定度**：

```
SD(f_cal) ≈ SD(est) / rec
```

宽口径的 rec 高，放大少，因此**同样准确且更稳**。

**操作结论：用宽口径测量，再除以实测斜率做校准；不要为了"看起来保守"而选严格口径——那只是把偏差换成了更大的方差。**

## 七、这解释了"类别筛选 4.64 倍"的实质

前面测到：同一批数据，宽口径 4.166%、严口径 0.795%，相差 4.64 倍（六样本中位）。

现在知道这 4.64 倍的构成：

| 成分 | 宽 | 严 |
|---|---|---|
| 回收率 | 88.75% | 59.74% |
| 校正后的真实病毒占比 | 4.166/0.8875 = **4.69%** | 0.795/0.5974 = **1.33%** |

**两者并不相等（4.69% vs 1.33%），差 3.5 倍。**

这说明"类别筛选"不只是一个可校准的灵敏度差异——严格口径漏掉的那 40%，**其构成与宽口径不同**：宽口径里包含大量无法判定来源的命中（other 占 80%），它们被算进"病毒"里，但它们是不是病毒，本实验无法判定（spike 是真病毒，背景里的 other 不是）。

所以：
- **spike 校准能校正"灵敏度"，不能校正"背景的构成"**
- 严格口径测到的 1.33% 更可能接近"确定无疑的病毒"，宽口径的 4.69% 更像"含疑似信号的上界"

**这才是两条口径的真实关系：不是谁更准，而是谁回答不同的问题。**

## 八、需要补哪些数据才能更准

现在的 spike 是 **in-silico**（把测序读段按比例混入），它绕过了提取、建库、扩增三步。因此：

| 缺口 | 影响 | 补法 |
|---|---|---|
| **提取偏差** | in-silico 假设提取效率 100%；真实噬菌体衣壳抗裂解差异可达数量级 | 提取前掺入 DNA spike 或完整噬菌体颗粒（B2） |
| **线性范围** | 只测了 0.1–5%；0.01% 与 20% 两端未知 | 扩到 0.01% / 0.1% / 1% / 5% / 10% / 20% |
| **spike 多样性** | 只有 3 个有尾噬菌体（Myoviridae/Siphoviridae），GC 与长度相近 | 换成 6–10 个不同科、不同 GC 的病毒 |
| **背景构成真值** | `other` 占 80%，其中有多少是真病毒无法判定 | 需分选/单颗粒测序或已知 mock 群落 |

**没有第 1 项，"回收率 89%"只是"检测灵敏度"，不是"提取到测量"的全链条效率。**

## 九、一个必须记录的自我纠错

第一次计算时，我用错了校准式：`f_cal = (est − B)/rec`。结果四个规则都出现约 −4.7% 的系统偏差，看起来像"正常的模型误差"。

追查后发现：正确式子是 `(est − B)/(rec − B)`，而错误式的偏差恰好等于 `B/rec`（4.156/88.75 = 4.7%）——**误差大小正好等于背景占回收率的比例，因此伪装成了合理的残差**。

修正后误差从 4.7% 降到 0.2%。

这条要写进方法学：**校准公式的代数形式必须从模型严格解出，不能凭直觉写；否则偏差会以"看起来合理"的幅度静默存在。**

## 十、置信度

| 结果 | 值 | 依据 |
|---|---|---|
| 回收率（宽口径） | 88.75% / 89.28% | 3 水平 × 3 重复，R²=1.000 |
| 回收率（严格口径） | 59.74% / 55.07% | 同上 |
| 校准后误差 | ≤1.2% | 4 规则 × 3 水平 |
| 线性成立 | R² = 1.000 | 全部 4 个规则 |
| 可外推范围 | **0.1–5%**，不得外推 | 仅测此区间 |
| 全链条效率 | **未知** | in-silico spike 不含提取/建库 |

**可以声称**：在 0.1–5% 区间、本批背景、这两个库下，宽口径的检测回收率为 89±1%，校准后能把估计恢复到真值 1% 以内。

**不能声称**：不能声称这是"病毒占比的真实测量精度"——它只覆盖"检测到计数"这一段，不含提取与建库；也不能声称可外推到 5% 以上或 0.1% 以下。
