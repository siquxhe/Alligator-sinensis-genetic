## 四、规则（四条，违反即视为没做）

1. **先报 ID**。任何"改论文/写论文"的指令，开头必须带 ID（如"MS-01 继续写 Methods"）。我回复也以 ID 开头。没带 ID 就先问，不许猜。
2. **一个文件只属于一个工单**。所有稿件、图表、提纲都要在某张工单的"文件归属"表里登记一次；出现两份工单都认领同一文件，以工单为准并立即修正。
3. **版本号不跨工单**。v0.x 只在同一工单内递增；不同工单各自从 v0.1 起，禁止用"v0.3"这种号码跨线指代。
4. **推进即记账**。每次有实质推进：更新本工单的"待办状态"与"变更记录"（append-only，带日期），并在本看板同步那一行。

## 五、文件命名（新文件适用）

- 新稿件/新图表：前缀 `MS01_` 或 `CR01_`，如 `MS01_Manuscript_v0.4.md`、`CR01_Fig1_schematic`。
- 旧文件**不改名**（改动会破坏既有引用与 git 历史），一律靠工单的归属表登记说明。
