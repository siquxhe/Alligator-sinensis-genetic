# 从生物学原理出发：*Recording is not discovery* 的论证骨架

**日期** 2026-11-16　|　**定位** Perspective 的 §2/§3 重构方案（替换现有"检测模型 + 偏差清单"）
**上游文档** `Perspective_outline_Recording_is_not_discovery_2026-11-15.md`

---

## 一句话

**"记录"与"发现"的差别不是精度问题，是抽样问题。** 发现要求对总体无偏抽样；记录只能对"能进入记录器的那部分"抽样。而"能不能进入"由五层生物学机制决定，**每一层都不是随机筛除**。

现有 outline 的模型 `P = r × i × s × q` 是对的，但它把这四个因子当成"待优化的参数"。从生物学看，它们是**四个结构性偏斜**——优化只能让 P 变大，不能让它变 unbiased。

---

## 一、为什么必须换成生物学论证（而不是继续调参数）

现有 outline 的弱点，评审已经点到两处（`评审意见_CRISPR录制包_2026-11-16.md` §4、§5）：

1. **摘要数字与模型表差两个数量级**（写 `>10⁸`，自算是 `10¹⁰–10¹⁴`）；
2. **结论没有按基质分层**（粪便 10⁹–10¹⁰ 高于检出限，结论在那里不成立）。

这两处的共同根源是：**模型被当成"灵敏度计算"，而不是"偏斜结构的表达"**。

一旦把 P 理解成"灵敏度"，就会滑向"再优化一点就能用"；一旦理解成"四个偏斜的乘积"，就会看到：

> 即便把 r、i、s、q 各自提高 10 倍（P 提高 10⁴），你得到的仍然是一个**有偏的 10⁴ 倍**——更多记录，同样的偏差结构。

**这才是"不行"的真正含义：不是量不够，是质不对。**

---

## 二、五层生物学机制

每一层给：**生物学事实 → 推论 → 后果 → 可检验预言**。预言的作用是让论证可被反驳，这是 Perspective 与 opinion 的分界。

### 第一层｜受体识别是多对多，不是一对一

| | |
|---|---|
| **生物学事实** | 噬菌体的受体结合蛋白（RBP）与宿主受体不是锁钥关系。受体跨越蛋白（OmpC、FhuA、TonB 依赖转运蛋白）、糖缀合物（LPS、荚膜、壁磷壁酸）、菌毛、鞭毛等多种化学类型；同一噬菌体常需多个受体/共受体协同；同一受体可被多类噬菌体使用 |
| **推论** | "受体 R 对应的病毒集合"**不是一个良定义的对象**——它随宿主遗传背景、糖基化状态、膜电位而变 |
| **后果** | `r`（受体覆盖）无法从"受体身份"估计，只能对**已知配对**实测。因此 r 不是群落参数，是配对参数 |
| **可检验预言** | 即便构建 N 株受体诱饵，其捕获集合的并集也无法外推到未测群落；扩大 N 只增加已知配对的复现，不增加对未知类群的覆盖 |

**这一层决定了整个方案的类别**：它天然是"验证已知配对"的工具。这是结案报告 §4.1 的"鸡生蛋"，但理由不是"工程难"，而是**受体—病毒关系本身不构成可枚举的映射**。

### 第二层｜注入是主动过程，依赖宿主许可状态

| | |
|---|---|
| **生物学事实** | 吸附 ≠ 注入。注入需要：不可逆吸附的构象变化、膜电位、TonB-ExbB-ExbD 供能（对多种*siderophore* 受体噬菌体）、共受体招募、有时需要特定脂质环境。异源底盘常缺其中若干项 |
| **推论** | "能吸附"与"能注入"是两个独立的生物学门槛，且第二个是**底盘依赖**的 |
| **后果** | `i` 不是噬菌体的固有属性，而是"噬菌体 × 底盘"的联合属性。换底盘，i 变；同一底盘换受体，i 也变 |
| **可检验预言** | 同一受体在不同底盘上的注入率差异，会**大于**同一底盘上不同噬菌体的注入率差异。若成立，则"诱饵菌"的结论不可跨底盘外推 |

> **证据强度提示（2026-11-16 补）**：本层的"可检验预言"**目前没有直接文献支撑**，只有机制推理与 Zeng & Salmond 2020 的跨属间接证据。写作时必须标为 hypothesis to be tested，不得写成 established fact。详见 `五层证据表_W1_2026-11-16.md`。

**这一层解释了为什么"受体异源表达"在文献里成功与失败并存**：蛋白类受体（FhuA、OmpC）可移植，糖缀合物类受体依赖整套修饰通路，异源表达常"装上但不被识别"。这不是技术细节，是**受体化学类型决定的天花板**。

### 第三层｜记录的是"防御成功"，不是"感染发生"

| | |
|---|---|
| **生物学事实** | spacer 获取发生在 DNA 注入期（Modell 2017）；获取是低频事件（10⁻⁵–10⁻⁶/细胞）；新 spacer 需细胞存活并完成干扰建立才能被读出；烈性噬菌体感染后多数细胞被裂解，阵列随细胞消失；温和噬菌体建立溶原后阵列稳定遗传（Keith 2025 报告溶原提高获取） |
| **推论** | 读出的 spacer 分布 = **"成功防御的那一次感染"的分布**，不是"发生的感染"的分布 |
| **后果** | `s` 与病毒毒力**负相关**：越烈性的噬菌体越容易被系统漏掉。这不是随机噪声，是方向固定的偏斜 |
| **可检验预言** | 同一群落中，记录的 spacer 对温和/休眠噬菌体的富集度显著高于其对烈性噬菌体的富集度；且偏向早期注入区（Modell 2017 已证） |

**这一层是最致命的**：它意味着即便受体与注入都解决，读出仍然是**幸存者写的历史**。对"有没有来过"这个定性问题尚可接受；对"有哪些、多少"完全不可用。

### 第四层｜群落丰度是重尾的，检出限决定你看见哪一段

| | |
|---|---|
| **生物学事实** | 环境病毒丰度服从重尾分布：少数类群高丰度，大量类群稀有。多样性的主体在长尾 |
| **推论** | 任何有检出限的方法，观察到的"多样性"主要由**窗口位置**决定，而非群落本身 |
| **后果** | 提高灵敏度（降低 P 的损失）会先捞到**已知类群的低丰度成员**，而不是未知类群。这与"发现新病毒"的直觉相反 |
| **可检验预言** | 连续加深测序或提高捕获效率，新增序列中已知类群的比例**不下降或上升**；真正的新类群只在跨过某个阈值后才出现，且数量与投入不成正比 |

**这一层已有直接量化**：行星尺度 spacer 图谱显示，常见 spacer 的病毒匹配率为 **30.5%**，稀有 spacer 仅 **10.1%**——记录概率随丰度变化约 3 倍。也就是说，"提高灵敏度"在数据上首先表现为"发现更多常见病毒"。

**这一层把"再多做一点就能发现新病毒"这个直觉拆掉了。** 它也是按基质分层的依据：粪便 10⁹–10¹⁰ particles/g 高于现实检出限，那里限制因素不是丰度；海水 10⁶–10⁷/mL 才真正被丰度卡住。**结论必须分基质写，否则会被一句"粪便里明明足够多"推翻。**

### 第五层｜参考库的偏斜是按"是否被培养过"分层的

| | |
|---|---|
| **生物学事实** | 病毒"暗物质"比例 40–90% 无已知同源；RefSeq/PHROG 等库系统性偏向可培养、可分离、医学/农业相关的类群；本课题组实测也印证这一点：项目原用的 RVDB-prot v32 Unique 以真核病毒与 RNA 病毒为主，噬菌体蛋白严重不足，同一批 reads 换库后命中差 6 倍 |
| **推论** | `q`（spacer 能匹配上的概率）的缺失**不是随机**，而是按"目标是否被培养过"分层 |
| **后果** | 匹配成功 ⇔ 目标已在库中 ⇔ **它不是新发现**。这条构成一个自我否定的闭环 |
| **可检验预言** | 新 spacer 的匹配率随目标类群的培养历史单调变化；用"只含已培养类群"的库与"含环境 MAG 预测蛋白"的库分别匹配，差异应达数量级 |

**这一层还有第二个、更麻烦的问题：匹配不唯一。** 同一份行星尺度分析中，**60.8% 的匹配 spacer 同时命中两个及以上不同病毒基因组**；覆盖率也只有 36.1%（IMG/VR 序列）。原文措辞是「单次 spacer 命中可能具有误导性」。

**因此第 5 层的表述要升级为**：匹配成功 ⇔ 已在库中 ⇔ 不是新发现；**而且匹配上了也未必是那一个**。spacer 作为"病毒身份标签"的功能在已知类群内可靠（需 ≥10 条命中，76.8% 一致），跨类群时不可靠。

**这一层是本课题组有独立证据的一层**（`13_calibration/参考库核查_2026-11-15.md`）。它把"数据库不全"从一个技术抱怨升级为一个**结构性循环**：

> 要发现未知 → 需要 spacer 匹配 → 匹配需要库里有 → 库里有意味着已被发现。

## 三、五层合成：一个乘性漏斗，而不是一个灵敏度

```
群落病毒
  │ ① 受体不匹配            → 排除未知受体类群（结构性）
  │ ② 吸附但不注入          → 排除底盘不允许的（底盘依赖）
  │ ③ 注入但细胞裂解/Acr    → 排除烈性、被抗 CRISPR 的（方向固定）
  │ ④ 检出限之下            → 排除稀有类群（窗口效应）
  │ ⑤ spacer 匹配不上       → 排除未被培养的（自我否定）
  ▼
读出的 spacer 集合
```

`P = r × i × s × q` 仍然成立，但**四个因子的含义要改**：

| 因子 | 现有 outline 的说法 | 生物学版的说法 |
|---|---|---|
| r | 受体覆盖（可优化的比例） | **不可枚举的映射**，只能配对实测 |
| i | 注入概率 | **噬菌体 × 底盘**的联合属性 |
| s | 存活并获取的概率 | 与**毒力负相关**的偏斜 |
| q | 数据库匹配概率 | 按**培养历史**分层的循环 |

**结论句（可直接用）**：

> 这四个因子相乘得到的不是"灵敏度"，而是"偏斜的复合"。提高任一因子只会放大记录量，不会改变记录集与群落总体之间的关系——**因为每一层筛除都不是随机的**。

## 六、这份框架自身的边界

必须写明，否则会被反手一刀：

1. **它不是"证明不可能"，是"界定可行域"**。五层每层都可被绕过一部分；论证的是"绕完之后仍然是有偏的"。
2. **五层不是完全独立**（②与③相关，④与⑤相关）。写的时候要说明"分层是为了论证清晰，不是因为机制独立"。
3. **第四层的重尾分布在不同基质参数不同**，不能用一个指数概括全部环境。
4. **"可检验预言"目前多数是推论，不是实测**。必须标注哪些已有文献支持、哪些是本框架提出待验的。

## 七、一句话

**现有版本论证的是"这个工具不够灵敏"；生物学版本论证的是"这个工具测的不是那个总体"。前者可以被更好的工程推翻，后者不能。**
