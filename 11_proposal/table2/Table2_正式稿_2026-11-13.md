## 一、英文投稿版（canonical）

**Table 2. Minimum reporting checklist for viral-fraction estimates from host-associated metagenomes.**

| No. | Item | What must be reported | Consequence if omitted | Effect measured in this study |
|---|---|---|---|---|
| 1 | Denominator | Whether host reads were removed before viral screening; host-removal tool and host reference version | Fractions are not comparable across studies | ≤1.2% (C2 vs C6); larger when host content is high |
| 2 | Reference space | Database name and version (e.g., RVDB-prot v32 Unique, nr, study-assembled vOTUs); whether a study-specific catalogue was used | Cross-study comparison is invalid | 5.6× (3.0–22.1×) |
| 3 | Category filter | Which functional categories of viral-like hits were retained; whether hits to host-homologous categories were excluded, and on what rule | Host-homologous hits are counted as viral | 7.1× (5.6–7.6×) |
| 4 | Counting unit (incl. detection level) | Read counts, contig counts, or abundance-weighted values; abundance threshold applied; whether the unit change also changes the detection level | Estimates are over- or underestimated and non-comparable | 5.4× (2.1–19.2×); ≈0.6× with the reference set fixed |
| 5 | Signal validation | Whether dual negative controls were run (shuffled sequences; reversed database) and the number of hits obtained | A 0.1% estimate cannot be distinguished from zero | 0 hits in both controls |
| 6 | Assembly | Assembler and version; N50; whether sequencing depth was considered when calling shared or unique vOTUs | Shared and unique calls are unreliable | N50 4.2–6.4 kb (original assembly 1.8 kb) |
| 7 | Host prediction | Tool and version; confidence threshold; whether predictions were externally validated; taxonomic rank reported | Genus-level claims are unreliable | Phylum 5/5, genus 2/5 (n = 5) |
| 8 | Negative results | Number of independent assays and the criterion applied in each | A reported zero is not credible | 0 acquired ARGs across three assays |

**Notes.**

(a) Values in the last column are the median (range) fold change across the six samples, computed with the other dimensions held fixed. They are not multiplicative: 1.01 × 5.6 × 7.1 × 5.4 ≈ 217, whereas the observed overall span is 171×.

(b) Items 1–4 correspond to the four dimensions in Fig. 1; items 5–8 concern reliability rather than definition.

(c) The denominator effect was measured in fecal samples with low host content (0.07–2.51%). Host-removal method choice can dominate in high-host or low-viral-biomass samples (Forbes et al., *Cell Reports Methods* 2025, doi:10.1016/j.crmeth.2025.101218).

(d) Host-prediction agreement was assessed against 19 prophages with MAG-confirmed hosts; iPHoP returned a prediction for 5 of these (phylum 5/5, genus 2/5).

(e) Zero acquired ARGs: geNomad AMR annotation returned 0 of 2,678 genes; CARD searches returned 66 hits (22 unique genes), of which only *gyrA* fluoroquinolone mutation models exceeded 60% identity; none was an acquired resistance gene.

(f) Items 1–8 complement MIUViG (Roux et al., *Nat Biotechnol* 2019, doi:10.1038/nbt.4306), which specifies reporting of uncultivated viral genomes rather than read-level fractions.

(g) Item 4 combines the counting unit with the detection level: in this study C2 counts read-level protein hits while C4 counts geNomad-assigned contigs. Mapping reads back to each sample's own viral contig set, so that only the unit changes, yields a contig-to-read ratio of ≈0.6 — the opposite direction. The 5.4× is therefore an upper bound on the unit effect; most of it arises from the detection level and the reference set.

## 三、设计说明（写进 Discussion 的两段）

**为什么第 4 列要放"本批实测影响"。** 一般的报告清单只给"应该写什么"，作者没有动力执行。加上实测倍数后，清单从**规范**变成**有代价的规范**——不写，读者就无法判断你的数字落在 171 倍区间的哪一端。

**与 MIUViG 的关系。** MIUViG 规范的是"未培养病毒基因组怎么报"（来源、质量、注释、分类、宿主预测），已有共识；本表规范的是"read 层占比怎么报"，尚属空白。两者互补，不重复。

## 四、可与正文对应的句子（Discussion 备用）

> We propose an eight-item minimum reporting checklist (Table 2). Items 1–4 formalise the four dimensions quantified in this study; items 5–8 address reliability rather than definition. Each item is paired with the effect size measured here, so that omitting it has a stated cost rather than a generic appeal to transparency.

> Unlike MIUViG, which standardises the reporting of uncultivated viral genomes, Table 2 targets the read-level fraction itself—the number most frequently quoted and least frequently defined.
