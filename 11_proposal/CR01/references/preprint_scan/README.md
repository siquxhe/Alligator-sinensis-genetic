# bioRxiv 预印本扫描（CR-01 撞车检测）

**日期** 2026-11-20　|　**用途** 检测是否有预印本先于本文提出同一论点

## 两条通路与实测性能

| 通路 | 能力 | 实测 |
|---|---|---|
| `api.biorxiv.org/details/biorxiv/{start}/{end}/{cursor}` | 全量，30 条/页，**无关键词** | 持续限速 15–25 页/分钟；19.5 万条需 **4–6 小时** |
| OpenAlex `primary_location.source.id:S4306402567` | 索引子集，200 条/页，带摘要 | **6.2 万条 / 约 10 分钟**，覆盖 bioRxiv 同期 **33%** |
| `www.biorxiv.org/search/...` | 关键词 | **403**，Cloudflare 拦截 |
| Europe PMC `SRC:PPR` | 关键词检索预印本 | 可用，覆盖 bioRxiv 约 22%（月度） |

## 本目录脚本

`scan_openalex.py`：按月分窗 + 页号翻页，标题级关键词过滤，断点续跑（`done_months_oa.txt`）。
在服务器上跑：`python3 -u scan_openalex.py > run_oa.log 2>&1`。

要跑官方接口全量，用服务器上的 `~/virome/preprint_scan/scan.py`（逐页遍历 + 完成度校验）。
两者都只写命中项，不落地全量数据。

## 结果

2024-01 至 2026-11-20：62,114 条标题，**6 条命中，0 撞车**。
命中项与判定见 `plans/CR01_系统检索记录_2026-11-19.md` §11.3。

## 注意

- 标题级扫描不读摘要，语义只出现在摘要里的撞车会漏；摘要级检索另见检索记录第十节。
- 覆盖率随时间上升（2024 约 15% → 2026 约 62–73%），近期覆盖最好。
