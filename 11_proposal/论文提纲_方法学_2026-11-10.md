# 论文提纲：方法学定位（v0.1）

**日期** 2026-11-10　|　**类型** Methods / Benchmark（非发现型论文）
**依据** 6 个扬子鳄肠道公共宏基因组（PRJNA539906）完成的完整试跑 + `10_reports/literature_check_2026-11-10.md` 的冲突点核查

---

## 一、定位：避什么、主打什么

### 1.1 主动避开的五个冲突点

| 冲突点 | 谁做过 | 处理方式 |
|---|---|---|
| 噬菌体携带抗氧化基因（catalase/SOD） | 196 个噬菌体基因组已报道锰过氧化氢酶；Gifsy-2 sodCI 是教科书案例 | **完全不提**，也不作为卖点 |
| 鳄类噬菌体治疗 | 海南大学（*Aeromonas*、*Edwardsiella*），有论文与专利 | 不碰 |
| 健康 vs 发病的菌群差异 | Hilevski et al. 2026，美洲短吻鳄 | 不碰 |
| 冬夏/禁食季节差异 | Tang et al. 2019（本数据源）；且原设计季节与个体完全混淆 | 不碰 |
| 鳄类病毒组"首次刻画" | 无人做，但纯描述性会被问"所以呢" | **降级为案例材料**，不作主论断 |

### 1.2 主打的唯一论点

> **在病毒信号仅占 0.1% 量级的宿主宏基因组中，"有多少病毒"这个数字高度依赖流程选择；而多数研究既不验证信号真实性，也不报告口径。同一批数据、不同流程，可以得出互相矛盾的结论。**

这句话的强度来自它是**可演示的**，而不是主张的：
- 同一批数据，contig 层面"六样本零共享"，reads 加权层面却有 5 个高丰度共有 vOTU —— **结论相反**
- 同一指标，两种算法差 **3–15 倍**
- 宿主预测，门级 5/5 正确，属级只有 2/5 —— **同一工具、同一批结果，可靠性差一倍以上**

方法学论文的优势在于：**不与任何人的发现竞争，反而可以把他们的研究当作应用场景引用。**

1. *When 0.1% matters: a validation framework for low-abundance virome analysis in vertebrate gut metagenomes*

## 三、摘要要点（按结构写）

- **背景**：宿主相关宏基因组中病毒 reads 常低于 1%，此量级下信号真实性与定量可比性均缺乏标准。
- **问题**：现有流程在（i）信号真实性、（ii）丰度口径、（iii）组装深度、（iv）宿主预测可靠性、（v）阴性结果判定 五个环节缺少可执行检查。
- **做法**：以 6 个鳄类肠道宏基因组为案例，逐环节设置对照与重复计算，量化流程选择对结论的影响。
- **结果**：给出每个环节的偏差量级（倍数），并识别出三处"同数据反结论"的典型场景。
- **结论**：提出一份五步检查清单，可在不增加测序成本的前提下执行。

## 四、章节提纲

### Introduction（约 800 词）

1. 宿主相关病毒组研究的共同困境：病毒占比低、宿主背景高、参考库不全
2. 现有流程的默认假设：信号即真实、口径可跨研究比较、工具输出即结论
3. 三个已被零星提及但未被系统量化的问题：组装伪影、丰度加权、宿主预测置信度
4. 本文目标：给出可执行的验证框架，而非新的发现
5. 明确声明：不主张任何生态学结论，仅讨论方法可靠性

### Results（五小节，对应五张主图）

**4.1 信号真实性：0.1% 量级的数字需要对照才成立**
- 双零假设：400 万条打乱序列 → 0 命中；比对反向库 → 0 命中
- 病毒样 reads 上限 0.675–0.702%，病毒特异估计 0.089–0.122%
- 论断：**不设对照时，0.1% 与 0% 无法区分**

**4.2 口径决定数字：同一指标相差 3–15 倍**
- contig 有无 vs 统一参考 + RPKM≥1 加权：W1–W2 从 0.013 → 0.192（14.9×）；S2–S3 从 0.180 → 0.611（3.4×）
- 与原文（ORF 比对 nr + MEGAN4 LCA，0.04–4.03%）相差 1–2 个数量级
- 论断：**跨研究比较病毒占比在方法学上不成立，除非口径一致**

**4.3 组装深度决定能拿到什么：N50 与基因组数**
- 同一批数据：原文 N50 1,802 bp，本研究 4.2–6.4 kb
- 产出 202 条中高质量基因组（Complete 29 / High 48 / Medium 125）
- contig 层面 84.5% 单样本特有 vs reads 层面 RPKM≥1 仅 5 个共有
- 论断：**"零共享"在很大程度上是组装伪影，不是生物学信号**

**4.4 宿主预测的可靠性必须外部验证**
- iPHoP 对 202 条基因组给出 83 条（41.1%）宿主归属，置信度 90–100
- 用 44 条 MAG 独立确证 19 条前噬菌体的宿主：**门级 5/5，属级 2/5**
- 属级错判均落在同科/同目内（*Citrobacter* vs *Escherichia* 等）
- 另标注 1 例明显假阳性（古菌 Thermoproteota）
- 论断：**置信度分数不等于分类阶元可靠性；属级结论必须外部验证**

**4.5 阴性结果需要多重独立检验**
- 获得性 ARG：geNomad 自带注释 0/2678；CARD 32 条命中中 0 条属已知家族；≥60% 一致度仅剩 gyrA 突变模型
- 论断：**单次注释的"零"不可信，三重检验的"零"可以写**

### Discussion（约 1200 词）

1. 五个环节的偏差量级汇总 → 一份"最小报告清单"
2. 与已有方法学工作的关系（低生物量样本的污染控制、病毒组参考库偏差）
3. 适用边界：本框架针对低丰度 dsDNA 病毒；RNA 病毒、ssDNA 病毒需另行处理
4. 成本收益：所有对照均不增加测序量，仅增加计算与设计
5. 局限（**必须写，且要写足**）：
   - 单一物种、6 个样本，属案例研究，不外推普适规律
   - 外部验证仅 19 例，统计效力有限
   - 参考库覆盖不足（注释率 36%），可能低估 cargo
6. 建议：把五步检查作为投稿附录的最小单元

## 七、必须补的工作（诚实清单）

| 缺口 | 为什么必须补 | 工作量 |
|---|---|---|
| **第二个数据集** | 方法学论文只有单物种案例，审稿必问泛化性。建议取一个公开的鸡或人肠道病毒组数据集，用同一框架跑 | 中（3–5 天） |
| 口径矩阵系统化 | 目前只比了两种算法。应加入至少 3 种常见做法（coverM、bracken、contig 有无），做成 4×4 影响矩阵 | 中（2–3 天） |
| iPHoP 验证样本扩增 | 19 例太少。可从公共数据中找已有的 MAG + iPHoP 配对，扩到 50+ | 中（3–5 天） |
| 双零假设扩展到基因组层 | 目前只做了 read 层。基因组层可用打乱 ORF 或反向翻译验证 | 小（1 天） |
| 代码与清单整理 | GigaScience/mSystems 要求可执行 | 小（2 天） |

**总计约 2 周**，且不需要新测序。
