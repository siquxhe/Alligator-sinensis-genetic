## 0. 一页结论

### 三条线

| 线 | 问题 | 时间 | 花钱 | 产出 | 定位 |
|---|---|---|---|---|---|
| **A 方法学短论文** | 同一批数据，"病毒占比"在不同定义下差多少？ | **6 周** | 0 测序 | 五口径表 + 检查清单 | side paper / 方法章节 |
| **B 幼鳄死因归因** | 幼鳄到底死于什么？ | 2026-11 至 2027-03 | 病理判读 + 可能的检测 | 死因谱 v1 + 病例归因表 | **主线** |
| **C 前噬菌体开关** | 前噬菌体诱导是不是"携带→发病"的开关？ | 2027 出眠期起 | 测序 + 诱导实验 | 机制论文 | 长期科学问题 |

### 未来 6 个月的时间分配（默认）

- **B 60%**：病理判读、数据归集、病例定义——这是主线的地基。
- **A 30%**：六周内写完投出，硬止损（原定四周，因稀释曲线组装成本修正为六周）。
- **C 10%**：读文献、谈合作、设计采样方案，不启动实验。

### 三个不要

1. 不要把 A 做成 8 周的"完美 benchmark"——6 个样本撑不起，第二数据集留作 follow-up。
2. 不要在病理定义建立之前做"病 vs 健康"菌群比较——分组依据不成立，结论会被个体差异吃掉。
3. 不要在没做宏转录组或诱导实验之前说"开关打开了"——DNA 层面只能说明"基因在不在"。

### 三个 Gate

- **G-A**：A 在 **6 周**内未投出 → 降级为技术报告 / 学位论文方法章节，不再追加分析。
- **G-B1**：2026-12-15 前确认送检是 16S 还是 shotgun、元数据能否对上 → 否则 B 阶段 3 不启动。
- **G-B2**：2027-03 死因解释率较基线无提升 → 换病理合作方或重新定义病例。
- **G-C**：2027-06 前没有候选标志物 → C 不启动诱导实验，转为方法学 / 资源论文。

## 2. 三条线：A / B / C 的关系

### 2.1 一句话

- **A 解决"怎么量"**：把"病毒占比"从一句口号拆成可比较的定义。
- **B 解决"是什么病"**：先建立病例和死因谱，再谈菌群。
- **C 解决"为什么发病"**：在 B 的病例上检验前噬菌体诱导是否是开关。

### 2.2 顺序的逻辑

```
A（测量工具 + 技术信誉）
        ↓
B（疾病定义 + 病例 + 样本平台）
        ↓
C（机制假设 + 纵向队列 + 诱导实验）
```

- A 是 B 的 Methods 章节：A 的检查清单直接进 B 的样本处理流程。
- B 是 C 的病例来源：没有病理定义，C 的"病例组"就是主观分组。
- C 是学位论文的科学核心：A 和 B 都可以是章节，C 是那条能讲五年的线。

### 2.3 不要把三条线混在一起

| 错误做法 | 后果 |
|---|---|
| 用 A 的 6 个公共样本回答 B 的临床问题 | 个体与表型无法回溯，结论不成立 |
| 用 B 的横断面数据回答 C 的因果问题 | 只能得到关联，不能得到"开关" |
| 用 C 的假设去倒推 B 的死因 | 循环论证，病理判读会失真 |
| 把 A 当主线，拖 2–3 个月 | 主线没进展，side paper 也不一定中 |

## 3. 怎么制定科研计划：五步法

这一节是"方法"，后面三节是"应用"。以后换方向，可以重复用。

### 3.1 先分层：方向 → 主线 → 阶段 → Sprint

| 层级 | 时间 | 本项目的例子 | 判断标准 |
|---|---|---|---|
| **方向** | 3–5 年 | 鳄类条件致病菌的噬菌体开关 | 值得讲五年，能招学生 |
| **主线** | 1–2 年 | 幼鳄死因归因 + 风险标志物 | 能产出 2–3 篇论文/章节 |
| **阶段** | 3–6 个月 | 病理定义 / 数据盘点 / 方法学论文 | 有明确交付物 |
| **Sprint** | 2–4 周 | 五口径表 / 稀释曲线 / 第一批切片判读 | 一周能看到进展 |

**常见错误**：把 Sprint 当方向，做了很多分析，但不知道为了回答什么。

### 3.2 从"方向"到"问题"：把名词变成可证伪的句子

| 方向（名词） | 问题（可证伪） | 好问题的标准 |
|---|---|---|
| 病毒组 | 同一批数据，"病毒占比"在不同定义下差多少？ | 可测量、可比较、有明确分母 |
| 死因 | 幼鳄死亡的可归因病因构成是什么？ | 有病例定义、有组织学依据 |
| 噬菌体开关 | 前噬菌体诱导是否先于发病出现？ | 有纵向样本、有诱导指标 |

**问题质量检查表**：

- 能否被数据推翻？如果什么结果都支持它，它就不是科学问题。
- 能否在现有/可获得的样本上测量？
- 与 prior art 的差异是否一句话说清？
- 时间和预算是否允许？
- 对保护区/领域是否有用？
- 什么结果会让你放弃它？

### 3.3 从"问题"到"最小证据链"

不要列 20 个分析，列 **3–5 个必须的证据**，并标记"已有/要采"。

以 C 为例：

| 证据 | 说明 | 数据/实验 | 现在有吗 |
|---|---|---|---|
| 携带 | 条件致病菌带前噬菌体 | 宏基因组 / MAG | 有（pilot） |
| 诱导 | 前噬菌体被切出/表达 | 宏转录组、丝裂霉素 C、亚抑菌浓度抗生素 | 没有 |
| 表型 | 毒素/ARG/氧化应激模块起作用 | RNA/蛋白、cargo 表达 | 只有 DNA |
| 时序 | 诱导先于症状 | 同一个体纵向配对 | 没有 |
| 因果 | 消除/回补改变表型 | 菌株工程、动物模型 | 没有 |

**最小可行研究**：先做"携带 + 诱导 + 时序"三条；表型和因果留到有条件时。

### 3.4 从"证据"到"数据/样本/实验"

每个证据写清五件事：

1. **样本**：几例、什么部位、什么时间点、配对关系。
2. **对照**：健康对照、空白对照、阴性对照、技术重复。
3. **方法**：测序深度、平台、引物/试剂盒、分析流程。
4. **时间窗口**：什么时候能采、什么时候能出结果。
5. **权属**：谁的数据、谁签字、谁署名。

### 3.5 从"数据"到"决策门"

每个阶段开始前，先写"什么情况下继续、缩小、停止"。示例：

| Gate | 时间 | 继续条件 | 停止/转向条件 |
|---|---|---|---|
| G-A | 2027-01 | 五口径表 + 阈值 sweep + 稀释曲线（2 深度）完成 | 6 周未完成 → 降级 |
| G-B1 | 2026-12-15 | 送检类型/元数据/权属确认 | 确认不了 → 阶段 3 不启动 |
| G-B2 | 2027-03 | 死因解释率提升 | 无提升 → 换合作方/重定义病例 |
| G-C | 2027-06 | 有候选标志物 + 可采到配对样本 | 没有 → C 不启动诱导实验 |

### 3.6 从"决策"到"交付"

每个阶段至少一个可交付物，避免"做了很多但没有东西"：

- 表：数据可行性盘点表、病例归因表、五口径表。
- 图：阈值 sweep、稀释曲线、case series。
- 报告：技术简报、死因谱 v1。
- 论文：A 的方法学短文、B 的死因谱论文。
- 代码/流程：GitHub repo + README + 版本号。

### 3.7 模板（可直接复用）

| 字段 | 填什么 |
|---|---|
| 问题 | 一句可证伪的话 |
| 假设 | H1/H2，写清方向 |
| 证据链 | 3–5 条，标"已有/要采" |
| 数据/样本 | 来源、数量、部位、时间、配对 |
| 方法 | 平台、深度、工具、版本 |
| 对照 | 阳性/阴性/空白/技术重复 |
| 样本量 | 先验估算或 pilot 依据 |
| 时间 | 阶段 + 窗口 |
| 交付 | 表/图/报告/论文 |
| 风险 | 最大 3 个，配应对 |
| Gate | 继续/停止条件 |

### 3.8 反模式

| 反模式 | 为什么错 | 替代 |
|---|---|---|
| 先做组学，再找问题 | 数据越多，越不知道要回答什么 | 先写问题，再列证据 |
| 用相关性代替因果 | 横断面只能给关联 | 纵向配对 + 干预/诱导 |
| 用"首次"当卖点 | 描述性论文会被问"所以呢" | 用问题/机制/方法定位 |
| 把 side paper 当主线 | 时间被吃掉，主线没进展 | 硬时间盒 + Gate |
| 没有样本时设计 100 个分析 | 分析不能替代样本 | 先做数据可行性盘点 |
| 把"未检出"写成"没有" | 检测限/数据库覆盖限制 | 三重检验 + 检测限 |

## 4. Track A：方法学短论文（3–4 周）

### 4.1 定位

**问题**：同一批肠道宏基因组，"病毒占比"在不同定义下差多少？跨研究比较在什么条件下才成立？

**核心论点**：病毒占比不是单一数字，而是"分母 × 参考空间 × 赋值方式 × 阈值"的函数；同一批数据可以给出 0.089% 到 15.23% 的答案。

**不主张**：不主张生态学结论；不主张"首次"；不主张哪个流程"正确"。

### 4.2 五口径的定义（Week 1 开工前必须先写死）

| 口径 | 分子 | 分母 | 参考空间 | 赋值方式 |
|---|---|---|---|---|
| **C1** reads / 全部 reads | 比对到 vOTU 的 reads | 全部 clean reads | 本批 9,980 vOTU | 计数 |
| **C2** reads / 非宿主 reads | 同上 | 去宿主后 reads | 同上 | 计数 |
| **C3** ORF 比对 nr | 病毒 ORF 命中数 | 全部预测 ORF | NCBI nr（原文口径） | MEGAN4 LCA |
| **C4** contig 阳性率 | 病毒 contig | 全部 contig | geNomad 判定 | contig 有无 |
| **C5** RPKM 加权 | ΣRPKM(病毒 vOTU) | ΣRPKM(全部 vOTU) | 统一参考 | 丰度加权 |

**差异来源要写清楚**：C1 与 C2 差**分母**（是否扣除宿主）；C3 与 C4 差**参考空间**（nr vs 本批 vOTU）；C4 与 C5 差**赋值方式**（有无 vs 丰度）。**五行不定义，"差两个数量级"就只是口号，Table 1 也画不出来。**

### 4.6 最低可发表单元（退路，v1.1 新增）

如果稀释曲线因算力或时间做不出来，A **仍然成立**，退路是：

| 保留 | 删掉 | 形态 |
|---|---|---|
| 五口径表（Table 1）+ 最小报告清单（Table 2）+ Fig 1–3 | 稀释曲线（Fig 4）、组装深度论断 | Brief Report / Observation |

可投 *Viruses*（Brief Report）、*Microbiology Spectrum*（Observation）、或 *Journal of Microbiological Methods*（Short Communication）。**先想好退路，才不至于为了凑齐六张图拖到八周。**

### 4.7 不做什么

- 不跑第二数据集（留作 follow-up）。
- 不扩到 50+ 宿主验证（5 例 case series 足够说明问题）。
- 不 claim"首次鳄类病毒组"。
- 不碰季节/生态结论。
- 不把 0.089% 和 4.03% 直接算倍数——先说明分母。

## 5. Track B：幼鳄死因归因（主线）

### 5.1 定位

**主问题**：幼鳄死亡的可归因病因构成是什么？感染性、管理性、先天性、不明原因各占多少？

**核心指标**：**死因解释率** = 有组织学依据的归因病例 / 总病例数。

**支线**：条件致病菌的溶源特征是否与发病/死亡相关（只做关联/标志物，不做"互作机制"）。

### 5.2 四阶段

| 阶段 | 时间 | 动作 | 产出 |
|---|---|---|---|
| **0 启动** | 2026-11 | 确认送检类型；清点库存；接洽病理 | 三件事的答案 |
| **1 盘点** | 2026-11/12 | 数据/样本/元数据/权属 | 数据可行性盘点表 |
| **2 病理** | 2026-12 至 2027-03 | 切片判读、病例归因、死因谱 | 死因谱 v1 + 病例归因表 + 组织学基线 |
| **3 标志物** | 2027-03 起（条件启动） | 病变部位菌群/前噬菌体分析 | 风险标志物候选清单 |

### 5.3 阶段 1 的盘点清单

| 项 | 要确认什么 | 缺失后果 |
|---|---|---|
| 送检类型 | 16S 还是 shotgun？ | 16S 看不到噬菌体，阶段 3 改新采样 |
| 样本部位 | 器官还是肠腔/泄殖腔？ | 器官可用于病因推断，肠腔只反映濒死状态 |
| 个体编号 | 样本—解剖记录—血液—数据能否一一对应 | 对不上则全部作废 |
| 库存 | 例数、器官、蜡块/冷冻配对、切片状态 | 决定病理判读的工作量 |
| 元数据 | 日期、保存方式、用药、饲养 | 决定混杂控制 |
| 对照 | 有无健康/无病变个体 | 无对照则判读说服力下降 |
| 权属 | 委托合同/送检单/数据使用许可 | 合规风险 |

### 5.4 Gate

- **G-B1（2026-12-15）**：送检类型 + 元数据 + 权属确认。
  - 是 → 阶段 3 可规划。
  - 否 → 阶段 3 不启动，B 转纯病理死因谱。
- **G-B2（2027-03）**：死因解释率是否较基线提升，且提升来自组织学。
  - 是 → 继续。
  - 否 → 换病理合作方 / 重新定义病例。
- **G-B3（2027-04）**：是否有足够"病原不明"病例。
  - 是 → 阶段 3 启动。
  - 否 → 阶段 3 缩减，转死因谱论文。

### 5.5 风险

| 风险 | 影响 | 应对 |
|---|---|---|
| 病理判读能力缺失 | 最大瓶颈 | 联系两家以上；切片数字化远程会诊 |
| 无健康对照 | 判读缺参照 | 从库存筛无病变个体；文献基线；标注间接 |
| 濒死效应 | 肠腔菌群不代表生前 | 病因推断只用病变部位 |
| 元数据错配 | 全盘作废 | 强制核对，不接受推测性对应 |
| 数据权属 | 合规风险 | 合同/送检单/书面同意 |
| 送检仅 16S | 支线做不了 | G-B1 前确认；改新采样 |

### 5.6 与保护区/送检方的沟通

保护区需要的是**死因谱**和**风险标志物**，不是一篇病毒组论文。把 B 包装成"帮助保护区降低幼鳄死亡"的技术服务：

- 交付：死因谱 v1 + 病例归因表 + 技术简报。
- 回报：数据使用许可、2027 采样窗口、长期合作。
- 边界：不公开个体/场区敏感信息；论文发表前给保护区看稿。

## 6. Track C：前噬菌体开关（长期）

### 6.1 问题与证据链

**问题**：同一条件致病菌被携带，为什么有些个体发病？前噬菌体诱导是否是"携带→发病"的开关？

| 证据 | 说明 | 数据/实验 | 现在有吗 |
|---|---|---|---|
| 携带 | 条件致病菌带前噬菌体 | 宏基因组 / MAG | 有 |
| 诱导 | 前噬菌体切出/表达 | 宏转录组、丝裂霉素 C、亚抑菌浓度抗生素 | 没有 |
| 表型 | 毒素/ARG/氧化应激模块起作用 | RNA/蛋白 | 只有 DNA |
| 时序 | 诱导先于症状 | 同一个体纵向配对 | 没有 |
| 因果 | 消除/回补改变表型 | 菌株工程、动物模型 | 没有 |

### 6.2 最小可行研究

- **设计**：同一个体纵向配对：健康 → 亚临床 → 临床 → 恢复。
- **样本**：病变部位 + 血液 + 粪便/泄殖腔拭子。
- **组学**：宏基因组（DNA）+ 宏转录组（RNA）。
- **实验**：分离条件致病菌；丝裂霉素 C / 亚抑菌浓度抗生素诱导；qPCR/RNA-seq 看前噬菌体切出与 cargo 表达。
- **对照**：同一体的健康时间点；无病变个体；空白/阴性对照。
- **样本量**：先做 10–20 例 pilot；不追求统计功效，先看方向。

### 6.3 2027 年能做什么

- 如果 B 的阶段 3 找到候选（如 *Aeromonas* / *Edwardsiella* / *Citrobacter* 前噬菌体与病变相关）：
  - 2027 出眠期做一次目的驱动采样；
  - 分离菌株，做诱导实验；
  - 宏转录组看表达。
- 如果 B 没找到候选：
  - C 继续作为假设，不强行启动；
  - 先把 B 的死因谱和资源论文做出来。

### 6.4 物种与合作策略

- **扬子鳄**：目标种；非损伤采样 + 机会性剖检；保护结论。
- **暹罗鳄**：模型种；受控实验、病理材料；但**不重复海南大学的病原分离和噬菌体治疗**。
- **海南大学**：潜在合作方，不是必须的竞争对手；优先谈合作（菌株、养殖场、斑马鱼平台），不自己从零分离。
- **科大李海组/段屹**：噬菌体生物学合作；明确分工——他们做噬菌体/诱导机制，你做鳄类样本/病毒组/流行病学。

### 6.5 不做什么

- 不在没有表达/诱导数据时说"开关打开"。
- 不把 cargo 数量当因果。
- 不把 iPHoP 属级预测当确证（MAG 确证只有 6/19 条件致病菌属）。
- 不把"噬菌体治疗"当核心科学问题（海南大学已占）。

## 13. 结论：三句话

1. **先做不花钱的两件事**：B 的数据可行性盘点 + A 的五口径表；它们互为支撑，且都不依赖新采样。

3. **每个阶段设 Gate**：A 只给 4 周，B 是主线，C 是长期；任何一条线连续 8 周没有交付物，就停下来复盘。
